# Video Screenplay Format

The screenplay describes events in time. It is a production-facing narrative document, not a shot list.

## Header

Begin with title, target duration, adaptation status, logline, and a short note naming unresolved story decisions. Do not include tool or workflow commentary.

## Scene template

```text
SCENE S01 — LOCATION — TIME
Purpose: ...
Beats: B01, B02
Approximate duration: 12 seconds

Starting state
What is visibly true before the action begins.

Picture and action
Concrete action in causal order. Use short paragraphs. Keep each paragraph to one primary action or a tightly linked reaction.

Narration or dialogue
Only lines that add unavailable information, character voice, or necessary emotional framing.

Environment sound
Sounds belonging to the world of the scene.

Ending state
The visible and dramatic condition that hands off to the next scene.
```

Omit an empty narration or dialogue section when none is needed.

## Writing rules

- Use present tense and observable verbs.
- State who performs each action.
- Preserve causal order and spatially legible entrances, exits, transfers, and object handling.
- Use concise visual detail that affects identity, emotion, continuity, or story comprehension.
- Treat voiceover as a scarce resource. It should not describe what the audience can already see.
- Use montage only for repetition, gradual change, elapsed time, or several examples serving one dramatic function.
- Keep crowds, battles, disasters, many unique locations, and simultaneous complex actions only when they carry essential narrative value.
- Do not specify close-up, wide shot, angle, lens, framing, focus, dolly, pan, tilt, crane, handheld, or equivalent camera instructions.
- Do not include model prompts, negative prompts, seeds, aspect ratios, or provider names.

## Final checks

The screenplay must be understandable when read without the source story. It must also be traceable: every scene lists the beat IDs it adapts, and every core beat has an observable consequence in the screenplay.
