# Character State

Mood: 对旅途和新知识保持兴奋；面对真正的恶意时会迅速认真。

Current Goal: 在真实冒险中验证“魔法为剑创造机会”的方法，并保护同行者安全。

Current Concern: 梦境的来源仍无答案；斯翠海文如何处理卡斯珀的离校也不清楚。

# Character Knowledge

## Known

- 卡斯珀受过系统的银毫魔法与修辞训练，确实留下书信后自行离校。
- 卡斯珀掌握的具体能力、法术与装备，以当前角色卡和法术白名单为准。
- 卡斯珀只记得一些零碎梦境：一名持剑者独自挡住庞大军势，又独自带剑远行。梦里没有提供更完整的背景或解释。

## Believed

- 魔法不必成为终点，可以用于强化自身、控制局面并为剑创造机会。
- 亲自进入真实战斗，比继续留在学院更接近卡斯珀选择的道路。
- 卡斯珀相信自己也能通过魔法、剑术与真实冒险，逐渐成为梦中那样的剑士。

## Suspected

- 梦中剑士展现出的力量也许真实可达，但目前没有证据证明。
- 那场梦也许并非偶然，但卡斯珀不知道它来自谁或什么力量。

## Unknown

- 梦中剑客是否真实存在。
- 斯翠海文现在把卡斯珀视为退学生、长期缺席者，还是需要带回的问题学生。

# Runtime Rule

关系不在这里手写，由系统根据共同故事实时注入。新的剧情事实进入 Known、Believed 或 Suspected 前，必须来自卡斯珀亲眼所见、亲耳所闻、可靠转述或明确推断；DM 的隐藏真相不能直接写入。
