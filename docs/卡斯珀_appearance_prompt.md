# 固定轮廓

卡斯珀是十八九岁的人类少年，身形清瘦挺拔，四肢修长，体态轻盈灵活。长期练剑使他的身体比普通法师结实，但仍没有成年战士那种厚重强壮的轮廓。

# 面部与头发

他的脸庞带着明显的少年感，五官清秀明朗，皮肤较白，灰蓝色眼睛明亮有神。观察新奇事物时，他的目光会骤然亮起来，像是发现了值得研究的魔法现象。

他留着略显蓬乱的深棕色短发。头发显然打理过，却总有几缕不听话地翘起，像是思考、赶路或练剑后忘了重新整理。平时他的表情坦率生动，笑意来得很快，好奇、兴奋和疑惑很容易直接显露在脸上。

# 服装与装备

他穿着由银毫学院服饰改造而来的轻便冒险装束，主色是深蓝、象牙白和银色。修身长外衣与短披肩保留了魔法学院式的精致剪裁和银色纹饰，衣角、皮带与旅行靴则留有长途跋涉和实战造成的轻微磨损。衣服内部藏有轻薄皮甲与金属护片，不妨碍施法和快速拔剑。

他不刻意展示家世，但布料、剑具和学院式装饰都过于精良，熟悉魔法教育的人可能看出他的出身并不普通。

他的腰间佩着一柄细长的单手剑。剑身与护手兼具实战性和魔法工艺，没有贵族礼剑用于炫耀的繁复装饰。

# 魔法视觉

施法时，银白与淡蓝色的魔力沿剑脊和刃口流动，在周围形成近似笔画、诗句韵律和剑路轨迹的发光符文。这些符号不是固定文字，会随着他的思考不断组合、拆解并改变方向。

# 习惯性姿态与情境变化

平时卡斯珀站姿放松，喜欢主动凑近正在交谈的人。谈到感兴趣的事情时，他会不自觉地挥手比画。思考魔法或剑术时，他常用手指在空中勾勒法术结构，目光会突然变得专注敏锐，与平时略显冒失的少年形成反差。

有人受到威胁时，他脸上的笑意会迅速消失，身体先一步挡到对方身前，一只手握紧剑柄，眼神从好奇明亮变得简单而坚定。
