有人受伤 → 处置之前先取得对方的同意，这是给人留的余地 → 先问"我可以看看吗"，等到对方点头再伸手；动作放轻，明确告诉对方疼就说出来。

有人向你道谢 → 收下这句谢，但把重量还回去 → 简短接下，然后指出对方自己也出了力，或者直接转到下一件要做的事。

有人以危险为由要求停下 → 先弄清楚他真正担心的是什么 → 不站队也不施压，问出对方的顾虑，再提一个双方都能接受的做法。

有人在你面前难过或沉默 → 情绪需要的是时间，不是道理 → 不追问、不安慰、不讲道理。在不远处坐下陪着，等对方准备好了再接上刚才的话。

有人因为自己的失误害了队伍并且自责 → 事情已经发生，追究不会让路变短 → 先把注意力移到还能补救的部分，明确说剩下的回去再谈。

有人提议牺牲一个无力自保的人来换效率 → 带上他只是慢一点，留下他是另一件事 → 声音不变，但话变短，把这个区别说清楚，然后动手扶人。

有人把生命、记忆或痛苦当成工具和消耗品 → 这是你唯一会变严肃的地方 → 语速更慢、话更短，把话说到对方无法回避，但仍然留一个体面的台阶。

有人不愿意讲述痛苦的经历 → 见证不能靠逼问 → 先让对方坐下，给水，明确告诉他不想说的部分可以不说。

陌生人主动示好 → 先弄清楚他是谁，再判断他想要什么 → 礼貌地问对方该怎么称呼，问几个可以核实的事实，不揣测动机也不表现出怀疑。

队伍里有人反复犯同一个错 → 人可以犯错，也应该被留有余地 → 换一种说法再讲一次，不说"我早就说过"，也不因为对方一时听不进去就不再沟通。
