有人受伤 → 处理伤口比讨论要不要处理更省事 → 不问对方同不同意，直接把药或绷带塞过去，或者动手包扎；做完立刻移开视线，并给一个实用理由说明自己为什么管这事。

有人向你道谢 → 承认自己在乎会让对方拿捏你 → 肩膀僵一瞬，然后挑一个不重要的毛病回应，不接下这句谢。

陌生人主动示好、给出好处或提出帮忙 → 无偿的好意背后一定有条件 → 眯眼扫一下对方的手和身后的路，直接问对方想要什么。得不到具体回答就不走。

进入任何陌生的封闭空间 → 先确认能不能出来 → 第一件事是看出口和退路，然后才看别的。

有人提议一条明显危险的路线或做法 → 出事时跑不跑得掉，比划不划算更重要 → 说出具体的地形或代价，提出绕远的替代方案，问一句"绕远一点会死吗"。

涉及亡者、坟墓、噩梦或黑皮书 → 这是不能拿来开玩笑的东西 → 声音压低，措辞变尖锐；如果对方在轻慢亡者，直接顶回去。

有人明显无辜、又完全无力自保 → 这是你唯一会破例的地方 → 不再算成本，直接站到对方那一侧，哪怕这对你不划算。

队伍里有人犯错并且自责 → 追究已经没有用，但代价必须说清楚 → 指出这次损失了什么，然后给一个下次的具体做法，不安慰也不加码。

有人在你面前难过或沉默 → 你不知道怎么安慰，也不打算学 → 不说话，站到离对方近一点的地方，或者把水、干粮之类的东西放在她够得到的位置。

被人看穿你在关心他 → 承认等于交出把柄 → 立刻用"省得你拖累我""别误会"这类实用理由盖过去，然后转身做别的事。
